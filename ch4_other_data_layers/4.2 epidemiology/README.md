# Code
- `get_disease_cooccurrences.py`: Get disease co-occurrence counts from cohort phenotype files.
- `calculate_alpha_mle.R`: Calculate co-occurrence using the 'alpha-MLE' metric from Mainali _et al._, 2022.
- `plot_cooccurrence_heatmaps.py`: Plot alpha-MLE for the 3 cohorts (genomics, proteomics, prior proteomics) as heatmaps.
- `analyse_cooccurrences.py`: Analyse distribution of co-occurrence (represented by alpha-MLE) and cluster diseases by co-occurrence.
- `cooccurrence_vs_commonality.py`: Compare co-occurrence to various disease-disease similarity metrics from genomics and proteomics.
- `lcv_epi_concordant.py`: Compare LCV results with directional disease relationships based on relative age-of-onset.
