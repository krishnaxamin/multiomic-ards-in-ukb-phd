# Code
- `abf_susie_coloc.R`: Script to conduct ABF colocalisation for all ARD pairs and SuSiE colocalisation for all possible ARD pairs. Results exported to `results/` directory.
- `abf_susie_coloc.sh`: Shell script to execute `abf_susie_coloc.R` on an HPC.
- `collate_coloc_results.py`: Collate individual results from `results/` to `results/coloc_results*` or `results/coloc_summaries*`.
- `post_coloc_analysis.py`: Categorise colocalised variants according to the 4 categories outlined in **Table M2.13-1**, map categorised variants to genes, and plot results. Outputs `~/data/internal/genomics/colocalisations/coloc_abf_susie.csv`.

# Data present
- `combo_regions*`: LD-independent blocks that cover variants associated with a pair of ARDs in a certain genomic region, generated by `~/ch2_genomics/2.6 fine_mapping/2.6.1 step1_identify_blocks.py`.

# Data absent
- `results/`: Output from `abf_susie_coloc.R`.
- `plots/`: Plots generated from scripts in this directory.
