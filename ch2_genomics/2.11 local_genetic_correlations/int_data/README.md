# Data
- `diseaseX_diseaseX_ldsc_results/`: Results from same-disease LDSC.
- `gwas_summary_stats_for_lava/`: Collated GWAS summary statistics in LAVA-compatible format.
- `loci_ld_blocks_only.txt`: LD block coordinates for use in `../step5b_run_lava_for_ld_blocks.R`.
- `loci_follow_up_genes.txt`: Follow-up gene coordinates for use in `../step5b_run_lava_for_genes.R`.
- `loci_follow_up_genes_biotyped.csv`: Follow-up gene coordinates from `loci_follow_up_genes.txt` with biotype information.
- `follow_up_genes_with_diseases.csv`: Follow-up genes and the disease pairs that hosted the correlation in the LD blocks that contain those genes.
