# Code
- `plot_variant_gene_sharing_fisher_cossims.py`: Calculate and plot variant and gene sharing and cosine similarities on the same set of axes. Correlations are only calculated for variant-sharing disease pairs as there is no statistic from gene-level MAGMA that makes sense to correlate.
- `variant_gene_sharing_table.py`: Create tables for which genes and variants are significantly shared between ARDs.
- `variant_sharing_pipeline_ld_blocks.py`: Calculate and plot associated LD block-sharing between ARDs.
