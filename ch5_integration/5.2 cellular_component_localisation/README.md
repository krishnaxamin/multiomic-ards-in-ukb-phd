# Code
- `go_tree_extraction.R`: Extract GO parent-ancestor relationships and the full names of GO annotations from the GO ontology tree.
- `gwas_go_cc_localisation.py`: Test genes annotated with top-20 (by absolute effect size) pathways for each ARD via genomics results for enrichment in GO-CC terms.
- `proteomics_go_cc_localisation.py`: Test all Olink panel proteins, and proteins annotated with top-20 (by absolute effect size) pathways for each ARD via Cox proteomics results, for enrichment in GO-CC terms.
- `gwas_vs_proteomics_go_cc_terms.py`: Compare GO-CC enrichment between genomics and Cox proteomics results.
