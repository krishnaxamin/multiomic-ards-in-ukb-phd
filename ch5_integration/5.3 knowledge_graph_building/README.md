# Code
- `ukbppp_pqtl_sourcing.py`: Source pQTLs from the UKB-PPP using the UKB-PPP's web portal.
- `identify_tissue_for_tissue_specific_rna.py`: Identify which tissues tissue-specific genes are specific to, using HPA data.
- `construct_kgs.py`: Pipeline to build tissue-specific cellular networks using known data and association-determined links.
- `get_n_nodes_edges.py`: Collate numbers of nodes and edges, including of each type, for each graph.
