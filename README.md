# multiomic-ards-in-ukb-phd

## `chX_abc`: code for Methods sections
Code used, along with intermediary data produced and used, in the analyses for this thesis, organised by Methods section. For example, code for **Methods M4.2** is in `ch4_other_data_layers/4.2 epidemiology`.

## `data`
Organised into `internal` and `external` data
- `internal`: Data produced by analyses or methods in this thesis, e.g., results from GWAS analyses, co-occurrence data for the 68 ARDs.
- `external`: Data from external sources or related to data sourced from external sources with minimal alteration, e.g., original Reactome protein annotations, Reactome-Reactome parent-ancestor relationships.

## `utils`
Code used either to produce data that did not fit within a particular Methods section or to contain functions for wider used within the Methods sections.

## `Supplementary Data`
Tables/data that could not be included in the written thesis and so are made available in this repository.
