# Code
- `reactome_ora.py`: Conduct overrepresentation analysis (ORA) on proteins significantly associated with ARDs using Reactome annotation terms.
- `reactome_gsea.py`: Conduct gene-set enrichment analysis (GSEA) on proteins using association statistics and Reactome annotation term.
- `hagr_ora.py`: Conduct ORA on proteins significantly associated with ARDs using ageing- and senescence-related gene sets from the Human Ageing Genomic Resource (HAGR).
- `hagr_gsea`: Conduct GSEA on proteins using association statistics and HAGR gene sets.
